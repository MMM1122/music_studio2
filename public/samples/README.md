# Original STUDIO starter samples

The six WAV files in this directory were synthesized specifically for this project using the reproducible Python standard-library recipe at `scripts/generate-samples.py`.

- `felt-kick.wav`: decaying sine kick with a short noise transient.
- `soft-clap.wav`: three short noise bursts.
- `dusty-shaker.wav`: short exponentially decaying noise.
- `velvet-key.wav`: original synthesized Cm7 chord.
- `air-texture.wav`: original synthesized Cmaj7 pad.
- `round-bass.wav`: original synthesized C2 bass note.

No commercial recordings or sample packs were used for these six sounds. These six sample files and the synthesis recipe are dedicated to the public domain under CC0 1.0. They may be used, modified, and redistributed, including in exported songs, without attribution.

Regenerate with `python3 scripts/generate-samples.py`. All samples are mono PCM16 WAV at 44.1 kHz.
