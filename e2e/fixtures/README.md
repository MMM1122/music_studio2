# Reference audio fixtures

`reference-clicks.wav` is an original 12-second, mono, 16 kHz PCM16 click train at 120 BPM, synthesized mathematically for STUDIO tests (1.2 kHz sine bursts with an exponential envelope). No recording or third-party music was used.

`reference-clicks.mp3` encodes that same synthetic signal with lamejs 1.2.1 at 64 kbps. The encoder was used temporarily to prepare this fixture; it is not an application dependency. Both audio fixtures are freely reusable for testing.
